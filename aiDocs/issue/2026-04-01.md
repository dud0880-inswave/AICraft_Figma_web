### 1.1 Vite 경고 메시지 (심각도: 낮음)

**증상:**
```
[vite] warning: `esbuild` option was specified by "vite:react-babel" plugin.
This option is deprecated, please use `oxc` instead.
```

**원인:**
- Vite 5.x에서 esbuild 옵션이 deprecated
- @vitejs/plugin-react가 아직 새 API로 업데이트되지 않음

**영향:**
- 기능에는 영향 없음 (경고만)

**해결 방법:**
- @vitejs/plugin-react 업데이트 대기
- 또는 경고 무시

## 2. 잠재적 이슈

### 2.1 대용량 Figma 파일 처리

**상황:**
- 노드 수가 매우 많은 파일 (1000+ 노드) 처리 시

**잠재적 문제:**
- NodeTree 렌더링 성능 저하
- 클러스터 생성 시 시간 소요
- 메모리 사용량 증가

**권장 해결:**
- 가상 스크롤링 적용
- 클러스터 생성 백그라운드 처리
- 페이지네이션 또는 지연 로딩

### 2.2 동시 편집 문제

**상황:**
- 여러 탭/브라우저에서 같은 프로젝트 동시 편집

**잠재적 문제:**
- 마지막 저장이 이전 변경 덮어쓰기
- 클러스터 일관성 문제

**권장 해결:**
- 낙관적 잠금 또는 버전 체크
- 실시간 동기화 (WebSocket)

### 2.3 Figma API 제한

**상황:**
- Figma API 호출 빈도 제한

**잠재적 문제:**
- 대량의 파일 추가 시 API 제한 도달
- 이미지 로드 실패

**권장 해결:**
- API 호출 캐싱
- 요청 큐잉 및 레이트 리밋
