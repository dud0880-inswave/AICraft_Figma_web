AICraft-Figma 사용자 가이드 Figma 디자인을 WebSquare 컴포넌트로 매핑하고 XML 코드를 자동 생성하는 도구

Figma 디자인 → 노드 매핑 → WebSquare XML 생성 → 미리보기 확인 → XML 다운로드

1. 시작하기

1-1. 접속

브라우저에서 서비스 주소로 접속합니다. (예: http://<서버주소>:5180)

1-2. Figma Access Token 준비 (최초 1회)

Figma 파일을 불러오려면 개인 액세스 토큰이 필요합니다.

  1. Figma 로그인 → 좌측 상단 프로필 → Settings
  2. Account 탭 → Personal access tokens 섹션에서 토큰 생성
  3. 생성된 토큰(figd_...)을 복사해 둡니다
💡 토큰은 프로젝트 설정(⚙ → 기본 탭)에 저장하며, 파일을 처음 추가할 때 입력할 수도 있습니다.

2. 프로젝트 관리 (대시보드)

접속하면 프로젝트 목록이 표시됩니다.

작업방법
프로젝트 생성우측 상단 새 프로젝트 → 이름 입력
프로젝트 이름 수정프로젝트 카드에 마우스 오버 → ✏ 아이콘
프로젝트 삭제카드에 마우스 오버 → 🗑 아이콘 (하위 파일도 모두 삭제됨)
파일 목록 이동프로젝트 카드 클릭
프로젝트 목록으로 복귀파일 목록 좌측 상단 ← 프로젝트 목록

매핑에 사용할 컴포넌트 목록·CSS·매핑룰은 프로젝트 단위로 관리됩니다.

3. Figma 파일 추가

파일 목록 화면에서 새 파일 추가 버튼을 클릭합니다.

  1. Figma Access Token — 프로젝트에 토큰이 없으면 입력란이 표시됩니다
  2. Figma File URL — Figma에서 복사한 URL 입력
    • 파일 전체: https://www.figma.com/design/xxxxx/...
    • 특정 노드(프레임)만: Figma에서 프레임 선택 후 우클릭 → Copy link to selection으로 얻은 URL (?node-id= 포함)

파일 카드 기능 (마우스 오버 시 아이콘 표시)

아이콘기능
🔄 새로고침Figma 최신 내용 다시 불러오기. 노드가 바뀌면 사라진 노드의 매핑은 자동 삭제되고, 변경 시 버전 올리기 확인
🗑 삭제파일과 관련 매핑·이미지 삭제
  • 완료 뱃지: 매핑 작업을 완료 처리한 파일 (자동 매핑 클러스터 생성 대상)
  • 노드 뱃지: 특정 노드만 등록한 파일

5. 노드 트리

Figma 디자인의 레이어 구조가 트리로 표시됩니다.

기본 조작

조작방법
노드 선택클릭 (뷰어에 파란 박스로 강조)
다중 선택Ctrl(⌘)+클릭 추가 선택 / Shift+클릭 범위 선택
키보드 이동↑ ↓ 이동, → 펼치기, ← 접기 (Shift+↑↓ 범위 선택)
펼치기/접기노드 앞 ▸ 클릭, 헤더의 ⊞(모두 펼치기) ⊟(모두 접기)
검색검색창에 노드 이름 입력. 상위항목 체크로 부모 표시 여부 선택, 전체 선택으로 검색 결과 일괄 선택
순서 변경드래그 핸들(≡)로 같은 부모 안에서 드래그 앤 드롭

매핑 상태 표시

  • 뱃지 xf:group — 매핑된 노드는 이름 앞에 매핑된 컴포넌트 태그가 초록 뱃지로 표시됩니다. 마우스 오버 시 컴포넌트 이름 툴팁
  • 뱃지를 끄면(⚙ 설정 → 매핑 컴포넌트 뱃지 표시 해제) 초록 점으로만 표시됩니다

그룹화

  • 노드 1개 이상 선택 → 그룹화 버튼: 선택 노드를 새 그룹으로 묶음 (레이아웃 구성용 가상 그룹)
  • GROUP/FRAME 노드 선택 → 그룹해제 버튼: 그룹을 풀고 자식을 상위로 이동

6. 매핑 작업

노드를 선택하면 매핑 편집기에서 WebSquare 컴포넌트를 지정할 수 있습니다.

6-1. 컴포넌트 매핑

  1. 노드 선택 (여러 개 선택하면 일괄 적용 모드)
  2. 컴포넌트 검색창에서 컴포넌트 선택 (예: group, button, input, gridView …)
  3. 선택 즉시 저장되며 변환 결과가 자동 갱신됩니다
  • 매핑 해제: 매핑된 노드에서 해제 버튼 클릭 (다중 선택 지원)
  • 매핑 초기화: 현재 파일의 모든 매핑 삭제 (되돌릴 수 없음)

6-2. CSS 클래스 지정

매핑된 노드 하단에 프로젝트에 등록된 CSS 파일별 클래스 목록이 표시됩니다.

  • CSS 파일 탭으로 파일 전환 (검색어는 탭을 옮겨도 유지)
  • 클래스 버튼 클릭으로 적용/해제 (파란색 = 적용됨)
  • 표시 구분:
    • 바인딩 클래스: 해당 컴포넌트에 연결 설정된 클래스
    • ⭐ 추천 클래스: 다른 파일에서 같은 구조의 노드에 자주 쓰인 클래스 (빈도 표시)
  • 클래스 검색: .클래스명 또는 일부 문자열로 필터

6-3. 커스텀 속성

key=value 형태의 속성을 추가하면 생성되는 XML 태그에 그대로 반영됩니다. (예: id, label 등)

7. 변환 결과 (미리보기 / 코드)

우측 패널에서 매핑 결과로 생성된 WebSquare XML을 확인합니다.

미리보기 탭 (기본)

실제 WebSquare 엔진으로 렌더링된 화면을 보여줍니다.

컨트롤기능
디바이스 프리셋데스크탑 / 태블릿 / 모바일 등 뷰포트 크기 전환
− / + / 100%미리보기 배율 조절
새로고침미리보기 다시 렌더링
  • 프로젝트에 등록한 CSS가 함께 적용됩니다
  • 탭 옆 * 표시는 엔진 로딩 중이라는 뜻입니다

코드 탭

생성된 XML 소스를 하이라이팅과 함께 표시합니다.

다운로드 / 완료

  • 다운로드: 파일명을 확인·변경 후 XML 파일로 저장 (브라우저 다운로드)
  • 완료: 현재 파일의 매핑 작업 완료 처리 → 자동 매핑 클러스터가 생성되고 대시보드로 이동. 파일 카드에 완료 뱃지가 붙습니다

8. 자동 매핑

한 파일에서 매핑을 완료하면, 같은 구조의 노드를 다른 파일에서 자동으로 인식해 매핑을 제안합니다.

동작 원리

  1. 파일 매핑 후 완료 클릭 → 매핑 패턴이 클러스터로 저장됨
  2. 이후 새 파일을 추가하거나 헤더의 자동 매핑 버튼을 누르면
  3. 클러스터·매핑룰과 일치하는 노드들이 자동 매핑 제안 모달에 표시됨
  4. 제안 항목을 검토하고 적용/건너뛰기 선택

매칭 방식 (2단계)

  • Base 모드: 노드의 구조(componentProperties 키 + 부모 정보)로 매칭 — 일반적인 패턴
  • Full 모드: variant 값까지 포함해 매칭 — 동일 variant 노드에 더 정확한 클래스 제안

매핑룰 (이름 기반 기본 매핑)

노드 이름 키워드로 기본 컴포넌트를 지정하는 규칙입니다. (예: 이름에 btn 포함 → button)
⚙ 설정 → 매핑룰 탭에서 키워드 추가/삭제/기본값 복원이 가능합니다.

💡 매핑을 변경하면 "같은 구조의 다른 노드에도 전체 적용할까요?" 팝업이 뜰 수 있습니다. 프로젝트 전체에 일괄 반영하려면 적용을 선택하세요.

컴포넌트 탭

매핑에 사용할 WebSquare 컴포넌트 목록(레지스트리)을 관리합니다.

  • 컴포넌트 추가: 이름 + 태그명(예: xf:group) + 기본 속성
  • 수정/삭제 가능. 프로젝트 생성 시 기본 컴포넌트가 자동 등록됩니다

CSS 탭

프로젝트에서 사용할 CSS 파일을 관리합니다.

  • 파일 업로드: .css 파일 선택 → 클래스가 자동 추출되고 컴포넌트에 자동 바인딩됨
  • 직접 작성: 새 CSS 추가로 내용 입력
  • 클래스 매핑: CSS 클래스를 어떤 컴포넌트의 후보로 보여줄지 연결 관리 (자동 매핑 재실행 / 매핑 초기화 지원)
  • 업로드한 CSS는 미리보기 렌더링에도 적용됩니다

매핑룰 탭

10. 자주 묻는 질문 / 문제 해결

Q. 파일 추가 시 "권한 오류"가 발생해요.
Figma 토큰이 유효한지, 해당 파일에 접근 권한이 있는 계정의 토큰인지 확인하세요.
Q. Figma에서 디자인을 수정했는데 반영이 안 돼요.
파일 카드 또는 헤더의 🔄 새로고침을 실행하세요. 삭제된 노드의 매핑은 자동 정리됩니다.
Q. 미리보기가 "엔진 로딩 중"에서 멈춰요.
잠시 기다린 후 미리보기 탭의 새로고침을 누르세요. 계속되면 브라우저 새로고침(F5) 후 재시도하세요.
Q. 자동 매핑 제안이 나오지 않아요.
자동 매핑은 완료 처리된 파일의 매핑을 기반으로 합니다. 최소 1개 파일을 완료했는지, 노드 구조가 실제로 같은지 확인하세요. 이름이 달라 매칭이 안 되면 설정에서 "노드 이름 포함"을 해제해 보세요.
Q. 업로드한 CSS 클래스가 매핑 패널에 안 보여요.
매핑된 노드를 선택해야 CSS 클래스 영역이 표시됩니다. CSS 탭에서 해당 파일의 클래스가 추출되었는지(개수 표시) 확인하세요.
Q. 작업 내용은 어디에 저장되나요?
모든 매핑·설정은 서버 DB에 프로젝트 단위로 저장됩니다. 브라우저를 닫아도 유지됩니다.
