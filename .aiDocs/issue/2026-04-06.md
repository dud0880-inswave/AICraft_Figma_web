### [해결] Figma refresh 시 전체 노드 auto-mapping 팝업 표시 (2026-04-06)

**증상:**
- Figma 파일 refresh 시 신규 노드 여부와 무관하게 전체 노드에 대해 auto-mapping 팝업 표시

**원인:**
- `figma_file_data`가 최초 refresh 전까지 저장되지 않아 `prevData = null` → 모든 노드가 신규 판단

**해결:**
- `isFirstRefresh` 조건으로 최초 refresh는 `newNodeIds: []` 반환
- 이후 refresh부터 이전 데이터와 비교하여 실제 신규 노드만 반환

**증상:**
- 새 요소 추가 후 refresh → auto-mapping 적용 시 기존 노드(`content_group` 등)의 클래스 사라짐

**원인:**

**해결:**
- keyword suggest에 신규 노드만 flat하게 전달 (`collectNewNodes`)
