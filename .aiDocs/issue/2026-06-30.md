## 해결된 이슈

### [해결] 버튼 커스텀 label 덮어쓰기가 출력에 반영 안 됨 (2026-06-30)

**증상:**
- 매핑 에디터에서 버튼에 커스텀 속성 `label`을 추가해도 변환 결과가 계속 Figma 텍스트(`label="See More"`)로 출력

**원인:**
- XML 변환 로직이 **두 곳에 중복 구현**되어 있음
  - `packages/client/src/utils/convert-xml.ts` (공유 유틸이지만 미사용)
  - `packages/client/src/components/ConvertedCodeEditor.tsx`의 인라인 `traverse` (실제 출력 생성)
- 처음에 미사용 파일(`convert-xml.ts`)만 수정 → 출력 무변화

**해결:**
- 실제 사용되는 `ConvertedCodeEditor.tsx` 인라인 `traverse`에도 동일한 label 덮어쓰기 로직 적용
- 두 곳 모두 일관 처리: 커스텀 `label` 존재 시 Figma 텍스트로 덮어쓰지 않음

### [해결] 입력란 공백 입력 차단 (2026-06-30)

**증상:**
- 커스텀 속성 등 input/textarea에서 스페이스바 입력이 안 됨

**원인:**
- `FigmaViewer.tsx`의 캔버스 패닝용 전역 Space 핸들러가 `window`에 등록 + 포커스 무관하게 `e.preventDefault()`

**해결:**
- `isTypingTarget` 가드 추가 (input/textarea/select/contenteditable 포커스 시 패닝 비활성화)
