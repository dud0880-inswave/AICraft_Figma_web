## 1. 버그 수정

### 1.1 Figma refresh 시 추가된 노드에 대해서만 auto-mapping 팝업 표시

**문제:**
- Figma 파일 refresh 시 전체 노드에 대해 auto-mapping 팝업이 표시됨

**원인:**
- `figma_file_data`는 최초 refresh 시에만 저장되므로, 최초 refresh 때 `prevData`가 null → 모든 노드가 신규로 판단됨

**수정 내용:**
- `POST /api/figma-files/refresh` 엔드포인트 (`packages/server/src/index.ts`)
  - 저장 전 이전 데이터에서 노드 ID 수집
  - 신규 노드 ID(`newNodeIds`) 계산하여 응답에 포함
  - `isFirstRefresh` 조건: 최초 refresh는 `newNodeIds: []` 반환
- `handleRefreshFile` (`packages/client/src/App.tsx`)
  - `newNodeIds`가 있을 때만 auto-mapping 제안 요청
  - cluster suggest: `nonNewIds`를 `existingMappingNodeIds`로 전달 (기존 노드 제외)
  - keyword suggest: 신규 노드만 flat하게 전달

### 1.2 refresh 후 기존 노드(content_group 등) 매핑 덮어쓰기 버그

**문제:**
- 하단에 새 요소 추가 후 refresh 시, 기존 노드(예: `content_group`)의 클래스(`sub_contents`)가 사라짐

**원인:**
- `filterToNewNodes()` 함수가 새 노드의 **부모 노드도 포함**하여 keyword 제안 대상에 포함
- keyword 규칙에 매칭되는 부모 노드가 제안 → 적용 시 기존 매핑의 `customAttrs` 덮어씀

**수정 내용:**
- `handleRefreshFile` 내 keyword suggest 호출 방식 변경
- `filterToNewNodes()` 제거, 신규 노드만 flat 수집하는 `collectNewNodes`로 교체
- 부모 컨텍스트 없이 순수 신규 노드만 keyword suggest에 전달
