## B. 당일 세션 작업 (미커밋 워킹 변경)

### 1. 미리보기 디바이스별 뷰포트(비율) 선택
- `ConvertedCodeEditor.tsx` 미리보기 탭에 디바이스 프리셋 토글 추가
  - 데스크탑(꽉 채움) / 모바일(375×667) / 모바일 L(414×896) / 태블릿(768×1024)
- 고정 디바이스는 px 뷰포트를 가운데 정렬 + 음영, 영역 초과 시 스크롤
- 기존 줌(25~300%)과 병행 동작 (디바이스 + 줌 함께 적용)
- iframe을 항상 동일 DOM 위치에 유지(wrapper 스타일만 변경) → 디바이스 전환 시 재로딩 없이 콘텐츠 보존
- iframe 너비 변경 시 내부 WebSquare 콘텐츠가 모바일 폭으로 반응형 리플로우

### 2. 입력란 공백 입력 막힘 수정
- `FigmaViewer.tsx`의 전역 Space 키 패닝 핸들러가 `window`에 등록되어 포커스 무관하게 `preventDefault` 호출 → 모든 input/textarea에서 공백 입력 차단되던 문제
- 해결: 핸들러에 `isTypingTarget` 가드 추가 (input/textarea/select/contenteditable 포커스 시 패닝 비활성화)

### 3. 버튼류 커스텀 `label` 덮어쓰기
- 매핑 에디터 커스텀 속성에 `label`을 지정하면 Figma 텍스트 대신 그 값으로 라벨 출력
- 대상: button / span(attribute), trigger / anchor(`<xf:label>` 내용, label은 attribute에서 제외)
- **중요**: 변환 로직이 두 곳에 중복 구현되어 있어, 실제 출력에 쓰이는 `ConvertedCodeEditor.tsx`의 인라인 `traverse`까지 함께 수정해야 반영됨 (→ issue 참조)

### 4. CSS 클래스 검색 완전일치 우선 정렬
- `MappingEditor.tsx` `filteredClasses` 정렬에 "검색어 완전일치" 최상단(-1) 우선순위 추가
  - 우선순위: 완전일치 > 선택 > 추천 > 바인딩 > 나머지
- 예: `btn` 검색 시 `.btn`이 `.btn_account` 등 부분일치보다 앞에 표시
- 검색어 맨 앞 점(`.`) 제거 처리로 `.btn` 입력도 정상 매칭
